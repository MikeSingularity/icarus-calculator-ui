# ADR-001: Upgrade to Vite v8 and ESLint 10

- **Status:** Implemented
- **Date:** 2026-04-06 (Initial) / 2026-04-06 (Completed)
- **Corpus/Module:** icarus-calculator-ui

## 📋 Context

The project's current testing and linting toolchain is failing due to version mismatches:

- **Vitest v4** requires APIs (such as `./module-runner`) that were introduced in **Vite v8**; the current **Vite v5** installation results in a `ERR_PACKAGE_PATH_NOT_EXPORTED` crash during test execution.
- **ESLint v8** is reporting invalid configuration properties (e.g., `__esModule`) when attempting to parse the modern flat-config file (`.eslint.config.js`), which is being transpiled as ESM.
- The project is currently using **React 18.3.1**, while **React 19.2.4** is the stable standard in 2026, offering better performance and integration with modern SSR and Cloudflare environments.

## 🎯 Decision

We will modernize the core dependency stack to resolve these infrastructure failures and align with 2026 industry standards.

- Upgrade `vite` and `@vitejs/plugin-react` to **v8.x**.
- Upgrade `eslint` to **v10.x** and migrate to the standard `eslint.config.js` flat-config filename.
- Upgrade `react` and `react-dom` to **v19.x**.
- **Definition of Done:** Both `/lint` and `/test` workflows complete with Exit 0, and `jCodeMunch` re-indexes the project without parsing warnings.

## ⚖️ Consequences

- **Positive:**
  - Resolves the Vitest runtime crash.
  - Standardizes ESLint flat-config usage, eliminating transpilation artifacts.
  - Improved compatibility with Cloudflare Pages via React 19.
- **Negative:**
  - Potential breaking changes in component behavior due to React 19's stricter hydration or context rules.
  - Requires developer machines to have a 2026-compliant Node.js runtime (v22+).

## 🔄 Alternatives Considered

- **Downgrading Vitest:** Rejected because the project intends to utilize modern Vitest v4 features, and keeping an old Vite version would hold back build performance.
- **Sticking to ESLint 8:** Rejected as it requires brittle workarounds for flat-config files that are natively supported by ESLint 10.

## ✅ Summary of Result

- **Action Taken:** Upgraded 15+ packages (Vite 8, React 19, ESLint 10). Renamed `.eslint.config.js` to `eslint.config.js`. Corrected `.tsconfig.json` to use `bundler` resolution. Added smoke test in `tests/smoke.test.ts`.
- **Key Metrics:**
  - Tech stack modernized to 2026 stable versions.
  - Lint errors: 0 (passing).
  - Tests: 2 smoke tests passing in Vitest v4.
- **Verification:** Successfully executed `/lint` and `/test` workflows with Exit code 0.
